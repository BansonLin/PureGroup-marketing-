# 提示詞包（Prompt Pack）v1 — 使用說明

## 檔案

| 檔案 | 給誰 | 用途 |
|---|---|---|
| `chatgpt-prompt.md` | ChatGPT（Deep research） | 主提示詞；【範圍】可切換總覽／分層／單一市場 |
| `gemini-prompt.md` | Gemini（Deep Research） | 主提示詞；含研究計畫 8 步驟檢核 |
| `claude-prompt.md` | Claude.ai（Research） | 主提示詞；強調矛盾表與可比性校準 |
| `country-module-template.md` | 三者皆可 | 單一市場深潛範本＋12 市場在地搜尋線索對照表 |
| `output-format-spec.md` | 正本 | 回報格式規範（三套提示詞內已內嵌） |
| `_core-brief.md` | 正本 | 研究簡報共用段落（三套提示詞內已內嵌；修改時改這裡再重組） |

## 建議執行矩陣

| 次序 | 範圍 | ChatGPT | Gemini | Claude.ai | 優先級 |
|---|---|---|---|---|---|
| r1 | 12 市場總覽 | ✓ | ✓ | ✓ | **必跑** |
| r2 | 第一層（日韓新港） | ✓ | ✓ | 選配 | 高 |
| r3 | 第二層（中馬泰） | ✓ | ✓ | 選配 | 高 |
| r4 | 第三層（越印菲印度） | ✓ | ✓ | 選配 | 中 |
| c1–c5 | 單一市場深潛：台灣、日本、新加坡、馬來西亞、越南 | 選配 | ✓ | 選配 | 中 |
| t1 | 主題：商業模式單位經濟（財報） | ✓ | — | — | 中 |
| t2 | 主題：法規原文（政府網站） | — | ✓ | — | 中 |
| t3 | 主題：跨國擴張案例／市場規模校準 | — | — | ✓ | 中 |

最低交付：r1 × 3 份。完整交付：r1–r4 × 2–3 AI ≈ 10–12 份。

## 操作步驟（每一次）

1. 開對應檔案，複製「=== 提示詞開始 ===」到「=== 提示詞結束 ===」之間全文。
2. 改第一行【範圍】。
3. 貼上、執行。ChatGPT 若問澄清問題 → 回「依提示詞內的預設執行」。Gemini 會先出計畫 → 核對 8 步驟 → 開始研究。
4. 等待（Deep research 通常 10–40 分鐘）。
5. 完成後複製**含 URL 的全文**，存入 `03-inbox/<ai>/`，檔名與開頭中繼資料依 `03-inbox/README.md`。
6. 全部跑完後通知 Claude：「收件匣有新報告，請整合成 V2」。

## 注意事項

- Deep research 有月配額；先跑 r1 × 3，看品質再決定 r2–r4。
- 不要為了省字數刪掉 AI 的來源清單；整合時要逐條驗證 URL。
- 同一份提示詞跑兩次會得到不同結果；若配額允許，r1 跑兩次（r1a、r1b）可提高三角驗證的強度。
- 若 AI 回報「找不到台灣官方市場規模」是正常的：台灣沒有官方「室內裝修市場規模」統計，整合時會以多角推估並標【示意】。
