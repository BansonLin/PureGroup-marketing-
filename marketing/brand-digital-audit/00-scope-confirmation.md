## F. 品牌架構方向（影響第 4 步一半內容）

| 選項 | 內容 | CEO 裁決 |
|---|---|---|
| F1 母品牌主導 | 「璞石集團」為主識別，五品牌為子線；官網整合為集團站＋子站 | |
| F2 多品牌獨立 | 各品牌獨立溝通，集團只在 B2B（璞域）與徵才時出現 | |
| F3 混合 | 創研＋好室共用「璞石」識別；Wayhome、Homatch 獨立；璞域對建商以集團背書 | |

> 我的建議是 F3，理由：創研與好室客群重疊（宜蘭住宅），共用識別省行銷費；Wayhome 是多門市品牌不歸集團命名；Homatch 面向全台電商客群，與宜蘭地緣無關。
